## 🚀 **Quick Start Guide**

### **1. Enable Caching (Instant Performance Boost)**
```python
from pebblemind.cache import get_cache

cache = get_cache()
await cache.start()
```

### **2. Enable Beautiful CLI**
```python
from pebblemind.ui import get_cli

cli = get_cli()
cli.print_success("PebbleMind is now 10000x better!")
cli.print_panel("Check out all the new features!", title="Welcome")
```

### **3. Enable Monitoring**
```python
from pebblemind.monitoring import get_monitor

monitor = get_monitor()
await monitor.start()

# Check health anytime
health = await monitor.get_health_status()
print(f"Status: {health['overall_status']}")
```

### **4. Start Using Conversation History**
```python
from pebblemind.ui import ConversationHistory
from pathlib import Path

history = ConversationHistory(Path("data/conversations.db"))
await history.initialize()

conv_id = await history.create_conversation("My Chat")
await history.add_message(conv_id, "user", "Hello!")
```

### **5. Run Tests**
```bash
# Install test dependencies
pip install pytest pytest-asyncio pytest-cov

# Run all tests
pytest tests/ -v

# With coverage report
pytest tests/ --cov=pebblemind --cov-report=html
```
